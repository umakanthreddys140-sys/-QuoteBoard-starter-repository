# QuoteBoard Docker assignment starter

Canonical repository: https://github.com/kalviumcommunity/quoteboard-react-docker-starter.git

QuoteBoard is a Vite React app with React Router routes `/` and `/quote/:id`.

## Start locally

```bash
npm ci
npm run dev
```

Confirm `/` and `/quote/1` work through the Vite development server. Then follow the provided assignment brief.

## Files to create

- `Dockerfile`
- `nginx.conf`
- `.dockerignore`

Do not commit `node_modules`, `dist`, environment files, or secrets.
